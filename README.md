# Student Registration System

## 1. Project Overview

The Student Registration System is a simple web-based application
developed to manage student registration and student information.

The system provides an easy-to-use interface for registering students,
viewing student details, and managing basic student information.

---

## 2. Features

- Student Registration
- Student Management
- Student Information
- Course Selection
- Gender Selection
- Mobile Number Validation
- Email Validation
- Registration Form Validation
- Contact Information
- Simple and User-Friendly Interface

---

## 3. Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
